# alinezam.com

Personal website of Ali Nezamolmaleki — founder, software engineer, and organic growth leader based in Berlin.

Built with [Astro](https://astro.build) and deployed to GitHub Pages.

## Stack

- **Framework:** Astro
- **Styling:** Tailwind CSS
- **Deployment:** GitHub Pages (via GitHub Actions)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
